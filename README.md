# Stop & Shoot (working name)
Installable web app (PWA) for marking photo/travel spots while on the road: GPS pin in one tap or via `?mark=1` (Siri/Google shortcut), voice notes, tags, nearby EV charging / gas / restrooms (OpenStreetMap + U.S. DOE AFDC), weather (Open-Meteo), golden/blue hour, parking & cautions notes, export GPX/CSV/JSON. Data stays in the phone's browser storage.
Rename: `python3 rename.py "New Name"`, then bump `CACHE` in `sw.js`.
